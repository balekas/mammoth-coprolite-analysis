# Mammoth Coprolite Analysis Scripts

Scripts used in:

Ancient Squirrel Coprolites Reveal Timing and Evolution of North American Mammoths

## Contents

- `priority_consensus.py` – combines mapping stringencies
- `PW_dist_slidingwindows_divergenceV5.R` – calculates pairwise divergence

## Requirements

- Python 3.x
- R

## Notes

These scripts were used for analysis of ancient DNA mitogenomes from coprolites.
